# WWE 2025–2026 catalogue coverage audit

Audit date: 4 October 2026 (Australia/Sydney). New-set imports are paused by user instruction.

## Scope and findings

The current split catalogue has 18 sets labelled 2025 or 2026, compared against
Topps' checklist index, Topps product/event pages, yearly release guides and event
checklist directories. Product label year is used: 2025-labelled products released
in 2026 are included. This is WWE coverage, not all wrestling promotions or digital
SLAM collections.

No absent released main boxed product was identified in the sources checked.
This is not a guarantee that every obscure promotional issue has been discovered.
The missing coverage identified is the three 2025 event-exclusive products and
both years' ongoing Topps NOW programmes, including their Hall of Fame and poster
subseries. The already-present 2026 WrestleMania Vegas boxed/on-demand set does
not replace the annual Topps NOW checklist.

## Corrections and remaining review

1. **2025 Royalty WWE — corrected:** removed the false card #100 heading and
   moved TSR-1 through TSR-5 into `100 PERCENT STRATUSFACTION RELICS`. The
   catalogue and database now contain 689 identities, matching the source.
2. **2026 Chrome Sapphire WWE — corrected:** removed the false card #1986
   heading and moved all 30 real 86T autographs into `1986 TOPPS AUTOGRAPH
   VARIATION`. The catalogue and database now contain 496 identities.
3. **2025 WWE x BAPE:** four catalogue records are labelled `BABY MILO Image
   Variations` with BMA-prefixed internal identifiers. The selling product page
   describes the four named short-printed variations under the base set. Review
   actual card images/backs and correct subset assignment while preserving IDs
   and ownership. The PDF contains 118 numbered entries; four separately described
   variations explain the catalogue's 122 total, so they must not be deleted merely
   because absent from the PDF's numbered rows.
